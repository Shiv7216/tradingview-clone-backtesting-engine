# Custom TradingView Clone and Deep Backtesting Engine

## Overview and Why I Built This
This is a custom backtesting engine similar to TradingView. Because TradingView is paid and costly, I built my own lightweight clone using Gemini AI with the essential tools needed to run historical backtests, and I have shared screenshots of the live clone and terminal output in this repository.

I also integrated Pine Script functionality. Pine Script is a language where you write your trading strategy as a script and apply it to charts to get key performance outputs like win rate, max drawdown, Sharpe ratio, and a complete trade execution list showing the P/L for every trade. While basic Pine Script is free on TradingView, testing deep history over the previous 2 to 3 years requires buying a paid subscription.

That is why I built this TradingView clone with Pine Script support. I downloaded historical market records from Kaggle to run deep backtesting on my own machine, and I used ChatGPT to write the script for my strategy so I could test everything free of cost.

(Note: I have uploaded the core backtest.py engine and terminal screenshots here, while keeping my personal strategy script private.)
